# Mezatron Envanter — güncellemeler

Bu depoda yalnız Mezatron Envanter programının **imzalı güncelleme paketleri** durur.
Programın kodu burada değildir.

- `surum.json`: son sürümün bilgisi ve imzası
- `mezatron-<sürüm>.zip`: program kodu

Kurulu program bu dosyaları kendisi indirir ve imzası tutmazsa kurmaz.
İnternet yoksa iki dosyayı USB ile taşıyıp tepsi simgesindeki "Güncelleme dosyası yükle (USB)" ile kurabilirsiniz.
